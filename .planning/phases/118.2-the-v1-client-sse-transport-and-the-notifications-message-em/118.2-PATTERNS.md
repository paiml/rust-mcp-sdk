**Core reader state** (`src/client/subscriptions.rs:188-201`):

```rust
/// Incremental UTF-8 + SSE decoding state for one response body.
struct PayloadState {
    body: hyper::body::Incoming,
    parser: SseParser,
    /// Bytes received but not yet decodable as complete UTF-8.
    bytes: Vec<u8>,
    /// Payloads already parsed and waiting to be yielded.
    pending: VecDeque<String>,
    /// The body reported end-of-stream (or errored) and must not be polled again.
    done: bool,
}
```

**Core loop — the four-function split that keeps cog ≤ 25** (`src/client/subscriptions.rs:207-231`):

```rust
fn sse_payload_stream(body: hyper::body::Incoming) -> impl Stream<Item = Result<String>> + Send {
    let state = PayloadState {
        body,
        // An EXPLICIT bound, not `SseParser::new()`'s default: this path's limit
        // is visible at the call site and can be tightened independently of the
        // shared one.
        parser: SseParser::with_max_buffer_size(MAX_LISTEN_LINE_BYTES),
        bytes: Vec::new(),
        pending: VecDeque::new(),
        done: false,
    };
    futures::stream::unfold(state, |mut state| async move {
        loop {
            if let Some(payload) = state.pending.pop_front() {
                return Some((Ok(payload), state));
            }
            if state.done {
                return None;
            }
            if let Some(error) = read_next_frame(&mut state).await {
                return Some((Err(error), state));
            }
        }
    })
}
```

> **Adaptation for this phase:** the GET path pushes into `self.sender` rather than yielding a
> `Stream` (RESEARCH, Standard Stack: "the GET path does not need one"). Keep the *same four-way
> split* — the split exists specifically to stay under the PMAT cog-25 budget and its own rustdoc
> says so. Substitute `sender.send(msg).await` (D-04, bounded channel) for the `return Some((Ok(..)))`.

**Frame read + bound check + end-of-body drain** (`src/client/subscriptions.rs:236-275`):

```rust
/// Read ONE body frame into `state`, returning `Some(error)` only for a
/// transport failure.
///
/// Extracted from [`sse_payload_stream`]'s `unfold` closure so neither function
/// exceeds the repo's cognitive-complexity budget (CLAUDE.md: cog ≤ 25, enforced
/// by the PR-blocking PMAT gate).
async fn read_next_frame(state: &mut PayloadState) -> Option<Error> {
    match state.body.frame().await {
        // End of body. Anything already in `pending` is still drained by the
        // caller's loop before the `done` check ends the stream.
        None => {
            state.done = true;
            None
        },
        Some(Err(e)) => {
            state.done = true;
            Some(Error::Transport(TransportError::Request(e.to_string())))
        },
        Some(Ok(frame)) => {
            if let Some(chunk) = frame.data_ref() {
                state.bytes.extend_from_slice(chunk);
                let text = take_utf8_prefix(&mut state.bytes);
                state
                    .pending
                    .extend(drain_sse_payloads(&mut state.parser, &text));
                if let Some(error) = listen_overflow(&state.parser) {
                    // The peer pushed the parser's retained state plus this
                    // chunk past MAX_LISTEN_LINE_BYTES, so the parser DISCARDED
                    // bytes and this byte stream is no longer trustworthy.
                    state.done = true;
                    return Some(error);
                }
            }
            // A trailers frame carries no data; the caller loops and reads again.
            None
        },
    }
}
```

**Event filter** (`src/client/subscriptions.rs:285-292`) — replaces the existing
`if event.event.as_deref() == Some("message") || event.event.is_none()` at
`streamable_http.rs:1044` and `:1694`:

```rust
fn drain_sse_payloads(parser: &mut SseParser, chunk: &str) -> Vec<String> {
    parser
        .feed(chunk)
        .into_iter()
        .filter(|event| event.event.as_deref().is_none_or(|name| name == "message"))
        .map(|event| event.data)
        .collect()
}
```

**Named stream-ending error — the D-02 and D-05 template** (`src/client/subscriptions.rs:294-326`):

```rust
/// It names the limit and the peer's behaviour and nothing else — no frame
/// content is echoed, because the bytes that tripped the bound are exactly the
/// untrusted input [`MAX_ECHOED_FRAME`] exists to keep out of a client's logs.
///
/// A free function over the parser rather than an inline check in
/// [`read_next_frame`] so the condition is reachable from a test: that function
/// owns a live `hyper::body::Incoming`, which cannot be constructed outside hyper.
fn listen_overflow(parser: &SseParser) -> Option<Error> {
    if !parser.overflowed() {
        return None;
    }
    Some(Error::protocol(
        ErrorCode::INVALID_REQUEST,
        format!(
            "a subscriptions/listen chunk pushed the buffered stream state past the \
             {}-byte parser bound; the buffered bytes were discarded and the stream \
             was ended",
            parser.max_buffer_size()
        ),
    ))
}
```

> **D-05 (unparseable frame ends the stream) takes this exact shape.** Free function over the
> already-decoded payload so it is testable without a `hyper::body::Incoming`; message names the
> failure and echoes **nothing** un-truncated. If any frame text is echoed, reuse
> `truncate` (`subscriptions.rs:329-350`) — that is the bounded-echo control (ASVS V7).

### `src/server/core.rs` (service, request-response) — D-07 shared unit, D-13 arm

**The shared-unit pattern** (`src/server/core.rs:4485-4532`):

```rust
/// Resolve which peer a handler sees, request-scoped first, then the global one.
///
/// The ONE unit both native dispatch roots call — `ServerCore::attach_peer` and
/// `Server::attach_peer`. ... the precedence rule is the kind of thing two
/// roots must never disagree about, and a rule spelled twice is kept in step by a
/// comment instead of by the compiler. Both roots previously carried this body verbatim.
///
/// # Ordering
///
/// Every dispatch site calls this AFTER its `tool_authorizer` check, so an
/// unauthorized caller returns before a handler body ever runs.
#[cfg(not(target_arch = "wasm32"))]
pub(crate) fn attach_request_peer(
    extra: crate::server::cancellation::RequestHandlerExtra,
    global: Option<&Arc<dyn crate::shared::peer::PeerHandle>>,
) -> crate::server::cancellation::RequestHandlerExtra {
    // Cloned out of the borrow before `with_peer` consumes `extra`.
    let request_scoped = extra
        .protocol_context
        .as_ref()
        .and_then(crate::types::protocol::ProtocolContext::transport_backchannel)
        .and_then(crate::types::protocol::context::TransportBackchannel::peer)
        .cloned();
    if let Some(peer) = request_scoped {
        return extra.with_peer(peer);
    }
    if let Some(peer) = global {
        return extra.with_peer(peer.clone());
    }
    extra
}
```

## Shared Patterns

### 1. One shared unit called by BOTH dispatch roots
**Source:** `src/server/core.rs:4514` (`attach_request_peer`), delegated from
`src/server/core.rs:747` and `src/server/mod.rs:1248`.
**Apply to:** `src/server/cancellation.rs`, `src/server/core.rs`, `src/server/mod.rs` (D-07, D-13).
**Rule, quoted from the source:** *"the precedence rule is the kind of thing two roots must never
disagree about, and a rule spelled twice is kept in step by a comment instead of by the compiler."*
**Precedence for the log sink:** request-scoped `TransportBackchannel::notification_sink` first,
then the root's fallback — `Server`'s `notification_tx`-derived closure
(`src/server/mod.rs:1296-1299`), `ServerCore`'s a literal `None`.
**Ordering:** attach at the same site as `attach_peer`, which is already AFTER the
`tool_authorizer` check (ASVS V4; Pitfall 12).

### 2. Paired `#[cfg]` accessor with a constant `full-v2` twin
**Source:** `src/shared/streamable_http.rs:709-729` (`resumption_callback` pair);
`src/server/streamable_http_server/v1_session.rs:243` ↔ `v1_session_off.rs:102`.
**Apply to:** D-03's `reconnect_cursor()`, D-11's session log-level accessors.
**Rule:** the *call site* carries no `#[cfg]`. The twin takes the identical parameter list, returns
an owned constant, and declares nothing the real module does not. There is exactly **one** existing
call-site `#[cfg]` in `streamable_http.rs` (`:970`) and its comment asks that a second not
accumulate.

### 3. Fail loudly rather than synthesize
**Source:** `src/client/subscriptions.rs:312-326` (`listen_overflow`);
`PeerHandle::elicit`'s default body returning `METHOD_NOT_FOUND` rather than a forged `ElicitAction`.
**Apply to:** D-02 (parser overflow) and D-05 (unparseable frame) — both **end the stream** with a
named error rather than `if let Ok(..)`-dropping. One story for corruption, not two.

### 4. Untrusted-input error messages: name the limit, echo nothing

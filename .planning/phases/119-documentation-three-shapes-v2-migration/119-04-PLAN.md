| test process → spawned example child processes | Child processes bind a real port and can outlive the test if not reaped, wedging every later run on the same port. |
| `target/debug/examples/*` → assertions | The tests assert against artifacts they do not build. A stale artifact yields a green test about code that no longer exists. |

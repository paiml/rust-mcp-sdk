<objective>
Give the Phase-109 fixture runner an **era dimension** (D-07): every fixture is replayed under both
MCP 2025-11-25 and 2026-07-28, observed differences are joined against the expected-difference
baseline by `observation_id`, and the join is BIDIRECTIONAL — an unlisted difference is a finding
AND a listed difference that no longer reproduces is also a finding. Along the way, perform D-08's
prose rename so bare "v2" always means the MCP era.

Purpose: CONF-02 requires the harness to gain v2 fixtures while v1 fixtures stay green. D-07 chose a
MATRIX over parallel `v1/`+`v2/` directories (duplicating 33 fixtures invites exactly the mirror-drift
defect Phase 115 fought four rounds over) and over an optional per-fixture `era` field (absence is
invisible, so v2 coverage would never be forced to grow). The seam already exists —
`ConformanceTarget` already abstracts in-process from over-the-wire — so this extends a working
mechanism rather than building a second one.

Output: an era-aware runner, an era-matrix driver over all 33 fixtures across the four reference
servers, and a baseline reconciled from measurement rather than from guesswork.
</objective>

constructor is v1-only for era purposes too. The transport that DOES carry v2 is
`pmcp::StreamableHttpTransport` (`src/shared/streamable_http.rs:1779`, which returns `true` with the
comment "This transport DOES have a wire representation for the negotiated version"). Any typed
client arm in this phase MUST use `StreamableHttpTransport`; `HttpTransport` is a trap.

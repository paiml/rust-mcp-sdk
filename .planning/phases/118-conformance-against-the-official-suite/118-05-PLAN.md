## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Conformance client -> example v2 endpoint | Arbitrary v2 requests, including deliberately tampered request state, cross here |
| Sealed request state -> server | An attacker-supplied `_meta` request-state blob is untrusted input that the server unseals |
| Environment -> process | `PMCP_REQUEST_STATE_KEY` is a secret read from the environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-118-21 | Elevation of Privilege | A hand-rolled crypto primitive in the example weakening the sealing the SDK already provides | mitigate | Acceptance criterion: `grep -cE 'aes\|chacha\|hmac\|Sha256\|ring::'` over the example returns 0; the example consumes `src/server/request_state.rs`, never reimplements it |

The artifact upload in plan 118-09 carries suite results, not the environment |

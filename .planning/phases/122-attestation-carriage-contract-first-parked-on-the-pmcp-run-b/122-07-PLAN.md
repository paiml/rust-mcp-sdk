<objective>
Extend carriage to the unit that actually ships to production — the team — and add the pack-time precondition that makes an attestation mean something.

D-08: attestation carriage covers server and team packages only. The user's rule, recorded verbatim because it is a rule to apply rather than a one-off: *"an agent is a team-of-one in its essence."* An agent that needs an attestation is wrapped as a team of one; `pack_agent` never grows the parameter, and `pack_workflow` is likewise out. Mechanically, all three single-layer kinds share `pack_single_layer`, so extending carriage to teams means threading an optional attestation through that shared helper — one mechanism, not two.

D-09: attestation implies resolved, the `cargo build --locked` analogue. If an attestation's subject digest covers a `ComponentRef::Range`, two environments with the same package digest run different code — dev resolves `london-tube@^1.2` to 1.3.0, prod resolves the same range to the 1.2.0 it already has — so the attestation would attest nothing about what actually runs while this phase ships a verification path implying otherwise.

Purpose: close SC2's team half and SC6's precondition half, and pin the depth limit as visible behaviour.
Output: an attestation parameter on `pack_team`, an `UnpackedTeam` return type, Gate A wired to 122-05's guard, and the team render states in `inspect`.
</objective>

<objective>
Build the exportable wire-level conformance harness (TEAM-06, D-17/D-19) corrected against every 109-07 review HIGH. The existing fixtures cannot be replayed (hard-coded generated ids `appr-42`/`mem-001`/`task-abc123`, assumed prior state, no expected schemas), and the old runner signature (`run_fixtures(server: Server, ...)`) cannot target HTTP or send `_meta`. This plan versions the fixture schema to v2 (adding `kind`, ordered scenario/setup grouping, deterministic seed/clock/ID injection, capture+substitution variables, expected tool input schemas, and wildcard/predicate assertions), abstracts the runner over a `ConformanceTarget` (in-memory `Client` over `DuplexTransport` AND an HTTP target — D-19), sends fixture `_meta` via the 109-00 low-level client API (`call_tool_with_meta` / `call_tool_with_task_and_meta`), asserts related-task SEMANTICALLY via `CallToolResult::related_task()` under `RELATED_TASK_META_KEY`, runs independent cases against FRESH server instances (stateful sequences use explicit ordered scenarios with capture/substitution against the deterministic id/clock seams from 109-03/109-04), and adds NEGATIVE harness tests proving the runner fails on extra tools / schema drift / a missing guard / a malformed fixture. Fixtures are regenerated to v2 with deterministic ids for every tool + every guard (D-20). Export the runner behind the `conformance` feature.

Purpose: Prove "advertised == enforced" at the wire level for all four reference servers with replayable, deterministic, schema-checked fixtures, and ship the runner the platform reuses.
Output: `src/conformance/runner.rs`, `tests/conformance.rs`, and regenerated v2 `contracts/team-servers/fixtures/**`.
</objective>

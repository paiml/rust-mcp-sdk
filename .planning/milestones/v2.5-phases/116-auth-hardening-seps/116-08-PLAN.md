Four invariants, all "never panic; errors are fine", and each stated so it does not merely restate
the implementation:

1. **`parse_credential_snapshot(<arbitrary bytes>)`** — never panics. Whenever it returns `Ok`, assert
   INDEPENDENTLY of the crate's own logic: every key returned by `keys()` has a non-empty `issuer()`
   (an entry can never be migrated without one — SEP-2352's rule, which the migration is the only
   thing enforcing), and `report.migrated() + report.dropped().len()` is at most the number of
   top-level entries the fuzzer's bytes could have described. This is AUTH-03's most hostile surface:
   the bytes come off disk, and a corrupt or attacker-planted `~/.pmcp/oauth-cache.json` reaches this
   parser before any authentication has happened.
2. **Round-trip stability** — whenever `parse_credential_snapshot(b)` returns `Ok((snap, _))`, then
   `parse_credential_snapshot(&snap.to_bytes()?)` must also return `Ok`, and the second snapshot's
   `keys()` must equal the first's. A parser/serializer pair that disagrees is how a "successful" save
   silently drops a login.
3. **`derive_application_type(<arbitrary Vec<String>>)`** — never panics for any vector of arbitrary
   strings, including empty, single-element, and mixed. Whenever it returns `Ok`, assert independently
   that `as_str()` is exactly one of `"native"` or `"web"` — the two wire literals SEP-837 defines.
   Derive the strings from fuzzer bytes with lossy UTF-8 and a bounded element count.
4. **`serde_json::from_slice::<DcrResponse>(<arbitrary bytes>)` then `.application_type()`** — never
   panics. Whenever deserialization succeeds, `application_type()` returns either `None` or a `Some`
   whose contents came verbatim from a JSON string in the input; assert the "verbatim" half by
   checking the returned `&str` is a substring of the lossy-UTF-8 rendering of the input bytes. This
   catches a stringification bug in the accessor that a `None`-only assertion would miss.

Module doc follows `pkce_helper.rs`'s: name the CLAUDE.md ALWAYS/FUZZ obligation, give the plain

Capture the four team-server tool contracts as a versioned provable-contracts YAML plus shared,
schema-versioned conformance fixtures (PKG-03), following the in-repo `contracts/*.yaml` house
convention. This is a contract-authoring job: it documents the tool surfaces and dispatch semantics

can run" (TEAM-06) real, with a schema stable enough that SDK and platform harnesses interpret them
identically.

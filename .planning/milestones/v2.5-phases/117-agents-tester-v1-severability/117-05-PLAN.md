<objective>
Make the `full-v2` severance build an actual merge blocker, and prove the blocking from the workflow
file rather than asserting it.

Purpose: D-02's mechanism is only worth anything if a broken severance build stops a PR. `ci.yml`
already contains the exact trap: a job named `feature-flags` (`:141-164`, "Feature Flag
Verification") that is ABSENT from `gate.needs` (`:443`) — visible, green-looking, and completely
non-blocking. The `gate` job does not fail automatically on a new `needs:` entry; it reads named env
vars and evaluates them explicitly at `:453-461`. Adding to `needs:` alone produces a job that is
awaited but whose result is never checked.

Output: a new `v1-severance` job, three coordinated `gate` edits, an automated wiring tripwire, and
one recorded adversarial observation.
</objective>

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in `#[test]` / `#[tokio::test]` + `proptest` + `cargo-fuzz` (libFuzzer, `+nightly`) |
| **Config file** | `Makefile` (targets `test`, `test-unit`, `test-property`, `test-doc`, `test-all`, `validate-always`) |
| **Quick run command** | `cargo nextest run --features full -E 'binary(<target>)'` — **`binary(...)`, never `test(...)`** (nextest selector pitfall) |
| **Full suite command** | `make quality-gate` |
| **External oracle** | `bash -o pipefail -c './scripts/run-conformance-suite.sh 2>&1 | tee "$log"'` then assert against `$log` (D-19 — never mask exit codes) |
| **Estimated runtime** | quick: seconds per binary; full gate: minutes; conformance suite: ~20 min both legs |

---

## Sampling Rate

- **After every task commit:** Run the plan's named `binary(...)` selector
- **After every plan wave:** Run `make test` (full test suite)
- **Before `/gsd:verify-work`:** `make quality-gate` must be green AND both conformance legs re-measured
- **Max feedback latency:** ~120 seconds for in-tree fences; the 20-min suite runs once per wave boundary at most, once at phase end mandatorily (D-08 re-measurement)

## Per-Gap RED→GREEN Proof Mechanics (D-09)

Each gap needs **one named artifact demonstrably flipped**, demonstrated RED *before* the fix:

1. Write the fence (golden literal / wire assertion) on the **unfixed** tree.
2. Run it; capture the failure verbatim into the plan's SUMMARY — non-negotiable RED evidence (D-04).
3. Land the fix. Re-run. Capture GREEN.
4. Record the before/after **on both legs** (some gaps move only one leg — say so).

For the four gaps whose only external witness is a suite scenario (`completion-complete`,
`resources-read-binary`, `tools-call-embedded-resource`, `tools-call-with-progress`): the in-tree
fence is the primary proof; the suite corroborates at re-measurement (D-08 forbids mid-phase
re-pin; a full suite run is ~20 min).

**Golden derivation rule (D-04):** byte literals are typed by hand from
`schema/vendored/core-2026-07-28/schema.ts`, each citing its schema line. NEVER derived from
pmcp's own serializer output — that is the fence-restates-the-rule shape that reopened Phase 115
four times.

```bash
rm -rf target/conformance-results     # conformance -o ACCUMULATES — rebuild the root or counts double
bash -o pipefail -c './scripts/run-conformance-suite.sh 2>&1 | tee target/conf-after.log'
echo "exit=$?"                        # capture-then-assert; never `| tail` (D-19)
```

**Baseline to beat** (`118-CONFORMANCE-GAPS.md § The measurement`): v1 `51/15`, exit 1, 11 scored
red, 66 checks; v2 `124/54`, exit 1, 7 scored red, 178 checks. `MIN_CHECKS_V1=66` /
`MIN_CHECKS_V2=178` are floors on checks **executed** — restate upward in the same commit as the
change that raises them, never downward.

## Three-State Disposition Rule (D-10)

Every gap ends in exactly one of **FIXED** (named RED→GREEN proof), **REFUTED** (measured evidence
it was never a defect), or **DEFERRED** (named residual, owner, stated reason). None end silently.
REFUTED/DEFERRED require `checkpoint:human-verify gate="blocking"`. `118-CONFORMANCE-GAPS.md` is
amended, never rewritten.

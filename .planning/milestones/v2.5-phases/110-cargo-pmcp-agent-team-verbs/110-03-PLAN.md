<objective>
Implement `cargo pmcp agent dev` (CLI-02): resolve `--source openai-compat|sampling|fixed`
(D-03, a clap `ValueEnum`) to either an `AgentEngine` run over a `CompletionSource`
(openai-compat default → Ollama localhost, or fixed offline via a lib-safe runner seam) or
a sampling-hosted `AgentServer` served over `pmcp::StdioTransport`. The agent definition is
LOADED from an `AgentPackage` (`--package`, or the scaffolded `./agent.package.json`, else a
built-in demo), not a hardcoded fixture. Endpoint handling is corrected to the real API:
a remote plain-http endpoint fails at source CONSTRUCTION (`CompletionError::Decode`) → actionable
error naming `--allow-insecure-http`; `AgentEngine::run` returns a `RunOutcome` (NOT a `Result`),
so a non-`Completed` outcome (unreachable/failed) is mapped to an actionable message naming
`--endpoint`/`--source fixed`. Fills the plan-110-01 stub in agent/dev.rs.

Purpose: One open agent loop, runnable locally two ways, consuming a real AgentPackage, matching
the shipped Phase 108 demo — with the error/transport contract modelled correctly (Codex 110-03 HIGH).
Output: A wired `agent dev` handler + a lib-safe fixed-source runner seam + an offline fixed-source
integration test + an automated in-process sampling-hosted test.
</objective>

| T-110-03-03 | Denial of Service | unreachable default endpoint | mitigate | `.run()` returns a `RunOutcome`; a non-`Completed` outcome is mapped to an actionable `bail!` naming `--endpoint`/`--source fixed` (correct contract — `.run()` never surfaces `CompletionError`, Codex HIGH) |

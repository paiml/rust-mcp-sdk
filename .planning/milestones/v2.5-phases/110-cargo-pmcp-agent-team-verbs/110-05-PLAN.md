<objective>
Implement `cargo pmcp package show|capture` (CLI-04). `show` opens a local OCI
image-layout `.pmcp` package, rejects zero/multiple-manifest indexes, reads the manifest
`artifactType` AND the config/layer media types to pick the kind (via a pure, lib-safe
`kind::detect_kind` leaf tried against BOTH sources — Consensus concern #3), unpacks the
typed manifest, and renders it fully offline via `pmcp-package`'s own API (D-04). `capture`
is a thin client that resolves a configured platform target (via a capture-local `--target`,
Codex MEDIUM) + a cached, non-expired token (reusing `cargo pmcp configure`/`auth`, D-04a; the
CORRECT `TokenCacheV1.entries.get` API, Codex HIGH) and POSTs the package with a Bearer header,
a request timeout, and non-2xx handling; when unconfigured or the token is expired it fails with
actionable guidance, never a panic. Ships the `pmcp-package = "0.1"` caret-pin tripwire (D-04b).
Fills the plan-110-01 stubs. The pure `kind::detect_kind` and `artifact_type_from_manifest_json`
fns are dependency-light leaves so plan 110-06 can mount them via a lib seam and fuzz the untrusted
manifest-parse boundary.

Purpose: Portable `.pmcp` packages are inspectable offline and capturable to the platform — with
the config/auth/HTTP contract modelled correctly.
Output: Wired `show`/`capture` handlers + a pure kind-detection + manifest-parse leaf + offline show
test (with edge cases) + unconfigured AND configured(mock) capture tests + caret-pin tripwire.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell → package show | User-supplied filesystem path to an untrusted `.pmcp` package |
| package → filesystem | Reading OCI layout blobs (potentially malicious/tampered) |
| package capture → platform API | Authenticated outbound POST with a cached Bearer token |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-110-05-02 | Information disclosure | cached Bearer token | mitigate | `access_token` is a plain String — never `println!`/log it; interpolate only into the `Authorization` header; acceptance-gated grep (Gemini LOW) |

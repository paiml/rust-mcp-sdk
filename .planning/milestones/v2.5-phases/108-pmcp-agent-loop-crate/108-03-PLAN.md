<objective>
Build the heart of the crate (AGNT-02, AGNT-03): the pure decision core and the thin async iteration engine that orchestrates the three seams, plus the `EffectTrace`/`DecisionTrace` replay substrate and the replay-safety property + digestion fuzz that guarantee determinism.

Review-driven corrections (Codex HIGH, all five): (1) the engine LOADS resumable state via `ConversationStore::load` and resumes from the checkpoint phase; (2) checkpoint ordering is crash-safe — save `RunPhase::PendingTools` BEFORE dispatching side-effecting tools and save the final state before returning; (3) the RUN outcome is `RunOutcome::{Completed, LimitReached, RetryRequired{class}, Failed}` so AGNT-02 retry classification is returned data, not swallowed; (4) limits come from data (`tokens_used` in RunState, `max_tokens`/`max_iterations` in `ResolvedAgentConfig`); (5) `evaluate_submit_result` uses the real `jsonschema` validator (dep added in 108-02), not a promise. The replay assertion compares DECISION SEQUENCES (a public `DecisionTrace`), not only final results.

The engine is a thin `loop {}` that only awaits the four seam calls (load/create_message/invoke_batch/save); EVERY between-await computation lives in pure, unit-testable, `Serialize`-able functions. No wall-clock, no RNG — iteration/token counters only.

Purpose: the pure/replay-safe checkpointed loop is the durability seam the platform reuses (design §8.1); it is the single most load-bearing contract in the phase.
Output: `iteration/{result,decide,engine}.rs`, `trace.rs` with `EffectTrace`/`DecisionTrace` + `ReplaySource`/`ReplayInvoker`, golden fixtures, replay-safety proptest, digestion fuzz.

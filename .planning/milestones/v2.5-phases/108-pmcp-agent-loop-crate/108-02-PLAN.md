<objective>
Scaffold the new `crates/pmcp-agent` 0.x experimental workspace member (mirroring the `pmcp-tasks` isolation precedent) and define the object-safe async effect-seam traits + the shared runtime-config contract the entire crate is built between — `CompletionSource`, `ToolInvoker`, `ConversationStore` (AGNT-01) plus `ResolvedAgentConfig`. This is the interface-first wave: it establishes the CONTRACTS that Wave 3 plans (iteration core, sources, invoker/config) implement against, so it also declares the full module tree with compiling stubs.

Review-driven contract hardening (Codex): `ToolCall` carries a stable `id` (so parallel `tool_use`/`tool_result` blocks correlate — the SDK already models this: `SamplingMessageContent::ToolUse{ id, .. }` and `ToolResult{ tool_use_id }`); `RunState` fixes its history type to the SDK `SamplingMessage`, adds a `tokens_used` counter and a checkpoint `RunPhase`; `InMemoryStore` uses `std::sync::Mutex` (no phantom dependency); and a `ResolvedAgentConfig` type binds instructions/tools/limits/schemas/model/endpoints so later plans do not assume it into existence.

Purpose: downstream plans receive the seam signatures, the shared `RetryClass`, `RunState`, and `ResolvedAgentConfig` directly, with no codebase scavenger hunt.
Output: a compiling `pmcp-agent` crate with three seams, `InMemoryStore`, shared error/retry types, `ResolvedAgentConfig`, an object-safety proof, and stub module files owned by later plans.
</objective>

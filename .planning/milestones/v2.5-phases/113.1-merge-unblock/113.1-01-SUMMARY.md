### ⚠️ Correction to the plans' PMAT probe command — a NEW measured trap

Both this plan's and plan 05's `<automated>` verify blocks specify:

```
pmat analyze complexity -p . --format json | python3 -c "... json.load(sys.stdin).get('files',[]) ..."
```

**That command silently measures nothing.** `--top-files` defaults to **10**, so the top-level
`files` array contains only the 10 most complex files in the workspace — and
`src/server/streamable_http_server.rs` is not among them (the top entry is
`cargo-pmcp/src/deployment/post_deploy_tests.rs`). The generator therefore yields zero
`handle_post_*` rows, and `assert len(rows)>=2` fails with an empty list rather than reporting
a real measurement.

The fix used throughout this phase is `--top-files 0` ("show all"), which reproduces the gate
exactly (30 / 31 at baseline, nesting_max 10 / 10). Measured top-level JSON keys are `summary`,
`files`, `top_files_limit`; `summary.files` is likewise truncated to 10.

This is the same defect class as `D-113-J` (documented PMAT recipes that emit nothing). It is
handed to plan 04 to record alongside D-113-J's existing `--file` 14/18 trap.

### ⚠️ UNTESTED RESIDUAL RISK

Per D-11, a control that comes back GREEN proves nothing and must not be cited as preservation
evidence. Recorded plainly:

1. **No test in the suite constrains that a v2 gate `Reject` on the middleware path fires
   `report_middleware_error` before returning the 4xx.** The behavior IS preserved in the tree
   (the call is present, asserted by grep at line 3380), but this plan has **no test evidence**
   for it. `T-113.1-03`'s mitigation is therefore weaker than the threat register claims: the
   extraction preserved the call, but nothing would catch a future removal.
2. **No check constrains the per-arm `Box::pin` inside `dispatch_message_fast`.** After the outer
   boxing added in Task 2, removing an inner one is invisible to both `make lint` and the
   subscription suites. `T-113.1-05`'s mitigation is likewise weaker than claimed.

No test was weakened, no test was added solely to make a control fail, and no alternative
control was hunted for.

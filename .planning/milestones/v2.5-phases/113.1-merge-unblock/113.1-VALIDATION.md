## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `cargo test` / `cargo nextest` (`Makefile:32` installs it; `Makefile:212` uses it) |
| **Config file** | none — standard cargo layout; `fuzz/` is a separate workspace |
| **Quick run command** | `cargo test --test v2_bounded_reads_tripwire --features full` (0.04 s) · `cargo test --lib --features full sse_parser` |
| **Full suite command** | `make test-all` (= `test-unit test-doc test-property test-examples test-integration`) |
| **Estimated runtime** | quick ~1 s · full suite minutes-scale |

**Gate command NOT covered by `make quality-gate`:** `pmat quality-gate --fail-on-violation --checks complexity` (0.5 s). Verified: `make quality-gate` (`Makefile:673-690`) runs fmt-check, lint, build, test-all, pmcp-package-gate, audit, unused-deps, check-todos, check-unwraps, validate-always, purity-check, comply — **PMAT appears nowhere**. Every verification step in this phase's plans must invoke it explicitly.

---

## Sampling Rate

- **After every task commit:** Run `pmat quality-gate --fail-on-violation --checks complexity` + `cargo test --test v2_bounded_reads_tripwire --features full` + the touched module's unit tests
- **After every plan wave:** Run `cargo nextest run --features full` + `make lint`
- **Before `/gsd:verify-work`:** `make quality-gate` AND the explicit PMAT invocation AND the per-function probe confirming ≤ 20 on both handlers AND the nightly fuzz run with output inspected
- **Max feedback latency:** 60 seconds (quick loop); full suite only at wave boundaries

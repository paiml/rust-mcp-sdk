<objective>
Add the TOUT-02 double-wrap tripwire: a high-precision structural detector that WARNs (all builds) and `debug_assert!`-fails (debug builds) when dispatch is about to text-wrap a `Value` that structurally resembles an already-built `CallToolResult` — the exact silent bug that caused the agent-lake 2-week outage. Includes a per-tool `suppress_double_wrap_check()` opt-out (D-08) that survives the builder→ServerCore conversion, and a helper-level decision fn so the debug-panic behavior is unit-testable in isolation. "One local run would have caught it."

Purpose: Make the silent double-wrap failure loud at authoring/CI time, with near-zero false positives, and with test seams that do not depend on end-to-end dispatch aborting.
Output: `looks_like_call_tool_result` free fn + a small tripwire decision helper, tripwire wired into both Payload wrap sites, suppress flag threaded into both dispatchers, precision + helper-level panic tests.
</objective>

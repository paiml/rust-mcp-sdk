<objective>
Ship the two remaining D-03 sugar layers for TOUT-01: `ServerBuilder::tool_with_result()` (D-03.2, typed closure returning a full `CallToolResult`, mirroring `tool_typed_with_output`) and `RequestHandlerExtra::set_result_meta()` (D-03.3, lowest-friction `_meta` retrofit for existing handlers). The `set_result_meta` plumbing is the sharpest design point (Open Q1 + Codex MEDIUM): `extra` is moved by value into `handle_output`, so a shared interior-mutable slot is required, its Mutex discipline matters, and its merge/collision semantics must be precise.

Purpose: Give both closure authors and existing hand-written handlers an ergonomic path to task-augmented results without implementing `handle_output` by hand.
Output: `tool_with_result` builder + wrapper tool, `set_result_meta`/`take_result_meta` with an Arc<std::sync::Mutex<..>> slot round-trip and defined merge precedence, tests.
</objective>

transitively through rustls's crypto chain, so `use zeroize::Zeroize;` in `pmcp`'s own
production code fails to compile with E0432. Plan 03 is specified to zeroize the decoded key
buffer, and that scrub is the accepted mitigation for threat T-113-05.
Output: `113-SPEC-RECHECK.md`, an updated `Cargo.toml`/`Cargo.lock`, and three new locked
error-code constants.

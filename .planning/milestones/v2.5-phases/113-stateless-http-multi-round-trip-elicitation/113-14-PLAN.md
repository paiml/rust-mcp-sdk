cover this use two DIFFERENT principals.

Output: a duplicate-key registration answered with a typed rejection instead of
an eviction; a per-entry generation token that scopes every removal to its
owner; and a live regression test opening two streams for ONE principal under

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated HTTP client -> `subscriptions/listen` route | An authenticated principal chooses its own JSON-RPC id; that id becomes half of the registry key |
| co-tenant clients under one `AuthContext.subject` | Multiple browser tabs / processes / a shared service account collapse onto ONE principal |
| notifier task -> `fan_out` -> subscriber channel | Concurrent `Server::send_notification` callers race against registration and teardown |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-113-69 | Denial of Service | `ListenRegistry::register` | mitigate | Task 1: occupancy check and insert under ONE write guard; a duplicate live key returns `DuplicateSubscriptionId` instead of dropping the incumbent's `mpsc::Sender`. Any principal picking another co-tenant's id can no longer terminate their stream. Proven by `duplicate_key_is_rejected_and_the_first_stream_survives` and the live `same_principal_id_reuse_rejects_the_second_and_spares_the_first` |
| T-113-70 | Denial of Service | `ListenGuard::drop` / `remove_entry` | mitigate | Task 1: per-entry `u64` generation captured by the guard and compared before removal, so a late-unwinding guard cannot reclaim a healthy successor. Proven by `a_guard_drop_cannot_reclaim_a_successor_at_the_same_key` |
| T-113-71 | Denial of Service | `fan_out` -> `disconnect_overflowed` | mitigate | Task 1: the overflow key carries the generation observed under the read lock; a stale disconnect removes nothing. Closes review CR-02's window (overflow evicts, successor registers, old guard drops). Proven by `a_stale_overflow_disconnect_cannot_evict_a_successor` |
| T-113-72 | Information Disclosure | `ListenRejection::message()` | accept | The new duplicate message reveals only that THIS caller already holds a stream for THIS id — its own state, not server-wide capacity. IN-02's global-cap saturation-oracle wording is untouched and out of scope |
| T-113-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no package and changes no manifest. `Cargo.toml` and `Cargo.lock` must be byte-identical after the plan: `git diff --name-only -- Cargo.toml Cargo.lock` returns empty |

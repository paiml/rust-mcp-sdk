  capability for tidiness.
- **A compiled equality test.** ADOPTED for `tests/property_tests.rs` in 115-17 — it can host a
  `#[test]` and see the seam. It cannot cover the fuzz copy, which lives in a crate the workspace
  `exclude` array hides from every gate (`D-115-AB`) and which has no test harness at all.
- **A source-text gate.** ADOPTED here as the covering mechanism: it reads all three files as TEXT,
  needs no feature flags, runs under `make quality-gate`, and additionally compares the extracted
  lists against the meta-schema-derived expectation — which is what catches WR-01's SECOND failure
  mode, the lockstep removal that today deletes coverage with zero test failures.

The result is that the expectation is written down exactly once as an assertion, the three walkers'
copies cannot drift from it or from each other, and the derivation that justifies it is a one-command
re-run recorded beside it.
